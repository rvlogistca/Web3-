# 🤝 Como Contribuir

Obrigado pelo seu interesse em contribuir com este projeto! 🚀

---

## 🐛 Como Reportar Bugs
- Verifique se o problema já não foi relatado em **Issues**
- Crie uma nova issue com:
  - Título claro e descritivo
  - Passos para reproduzir o problema
  - O que aconteceu e o que esperava que acontecesse
  - Capturas de tela, se possível

## ✨ Como Sugerir Melhorias
- Descreva a melhoria e o porquê seria útil
- Explique como funcionaria na prática

## 📐 Padrões de Código
- Mantenha código limpo e bem comentado
- Siga o estilo existente no projeto
- Teste suas alterações antes de enviar

## 🔄 Processo de Pull Request
1. Crie uma branch: `git checkout -b minha-feature`
2. Faça suas alterações
3. Commit: `git commit -m 'Adiciona minha feature'`
4. Push: `git push origin minha-feature`
5. Abra um Pull Request

## 🏷️ Etiquetas Disponíveis no Repositório
- `bug` — Algo não está funcionando
- `documentation` — Melhorias na documentação
- `enhancement` — Novas funcionalidades
- `contract` — Smart Contracts
- `token` — Token, carteira e metadados
- `security` — Questões de segurança
- `frontend` — Interface e visual
- `backend` — API e lógica de servidor
- `testing` — Testes e validação
- `dependencies` — Atualização de bibliotecas
- `deployment` — Publicação e hospedagem
